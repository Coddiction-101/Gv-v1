Hum directly solution nahi dekhenge. Pehle problem ko samjhenge, phir examples pe dry run karenge, phir brute force sochenge, phir optimize karenge, aur har step pe tum khud code likhoge VS Code me. Main sirf guide karunga aur review dunga.

Humara flow kuch aisa rahega:

1. Problem Statement Samjho

   * Question kya bol raha hai?
   * Input kya hai?
   * Output kya chahiye?
   * Constraints kya hain?

2. Examples Pe Investigation

   * 2-3 custom examples banayenge.
   * Pen-paper dry run.
   * Pattern observe karenge.

3. Brute Force Sochna

   * Sabse simple solution.
   * Complexity calculate karna.

4. Better Approach

   * Kya unnecessary work ho raha hai?
   * Kya data structure help karega?
   * Kya observation mil sakti hai?

5. Code Writing (Step-by-Step)

   * Main ekdum small tasks dunga.
   * Tum code likhoge.
   * Main review karunga.
   * Fir next step.

6. Debugging

   * Test cases manually chalana.
   * Edge cases pakadna.

7. Final Analysis

   * Time Complexity
   * Space Complexity
   * Interview Explanation

Aur ek important rule:

❌ Main poora code ek saath nahi dunga.
